USL Championship.

A live sports analytics project that shows how clubs move through the Eastern and Western Conference tables as match results accumulate across the season.

Open live visualization View all projects

Project concept

The USL Championship visualization tracks club movement matchday by matchday, using points, wins, goals, draws, losses, and goal differential to show how the season changes over time.

Instead of treating standings as a static table, the project turns the season into a movement story: clubs climb, fall, separate from the pack, flatten out, or make late pushes as new results are added.

The full project page includes interactive controls for metric, conference, and x-axis, with club crests used as visual endpoints for each trajectory.

What it shows

  1. Points race

    How clubs accumulate points and separate from the rest of the table.

  2. Momentum

    Which clubs are rising, flattening, falling, or making late pushes.

  3. Filtering

    Users can view both conferences together or focus on the Eastern or Western Conference.

  4. Replay

    The visualization can replay from the start of the season to the latest available data.

Why it matters

A standings table is useful, but it only shows the current state. A movement chart shows the story behind that state: how clubs got there, when they surged, and where the separation happened.

This project is also a template for future Nagle Analytics work: take a real dataset, add interaction only where it helps, and make the pattern easier to see than it would be in a table alone.
